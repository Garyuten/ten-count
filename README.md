# 10秒ピッタリゲーム

シンプルで直感的な10秒ピッタリを目指すタイミングゲームです。

## 遊び方

1. 「スタート」ボタンを押すとタイマーがスタートします
2. カウンターが0.00秒からカウントアップを開始します
3. 3秒経過すると数字が非表示になります（より難しくなります）
4. ちょうど10.00秒だと思ったタイミングで「ココ！」ボタンを押してください
5. 10秒との差に応じてスコアが表示されます
   - 10秒に近いほど高得点
   - 10秒ピッタリ（±0.1秒以内）で「すごい！ピッタリ！」と表示
   - 15秒経過すると自動的に終了（スコア0点）

## 特徴

- デジタル時計風の見やすい表示
- 3秒後にカウンターが非表示になる演出
- 直感的な操作性
- 10秒との誤差に基づくスコアリングシステム

## 技術仕様

- HTML5
- CSS3（アニメーション効果）
- JavaScript（タイマー処理）
- Google Fonts（DS-Digital）を使用したデジタル表示

## ファイル構成

- `index.html` - メインのHTML
- `css/style.css` - スタイルシート
- `js/script.js` - ゲームのロジック
